The application bundles libmtp 1.1.23 and libusb as separate dynamic libraries
under LGPL-2.1-or-later. The code is not modified; install names are adjusted to
@rpath for relocation. Exact versions and license texts are alongside this file.
Source and corresponding Homebrew build recipes:
  https://github.com/libmtp/libmtp/tree/v1.1.23
  https://github.com/libusb/libusb
  https://github.com/Homebrew/homebrew-core/blob/HEAD/Formula/lib/libmtp.rb
  https://github.com/Homebrew/homebrew-core/blob/HEAD/Formula/lib/libusb.rb
Users may replace the dylibs with ABI-compatible builds and re-sign the app.

The installer optionally installs the original macFUSE 5.5.0 core payload,
whose official download SHA-256 and product signature are checked at build time.
The macFUSE code and payload are not modified. Existing macFUSE >=5.5 is kept.
macFUSE is NOT covered by KindleDock's MIT license. Its separate license is in
MACFUSE-LICENSE.txt and at https://macfuse.github.io/. It restricts redistribution
bundled with commercial software without the author's prior written permission.
KindleDock is distributed free of charge. A commercial redistributor must obtain
any macFUSE permissions required for their own bundle.

macFUSE is loaded from /usr/local/lib; it is not copied into the app bundle.
No macFUSE source code has been incorporated into KindleDock.
